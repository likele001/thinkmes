# 物料、采购、订单关系与操作说明

## 一、三者关系概览

```
┌─────────────┐    按型号+数量     ┌─────────────┐
│   订单      │ ────────────────► │ 订单物料需求  │  (每个订单需要哪些物料、要多少)
│ (Order)     │                   │(OrderMaterial)│
└─────────────┘                   └───────┬───────┘
       │                                  │
       │ 物料需求按 BOM 计算               │ 缺料时自动生成
       ▼                                  ▼
┌─────────────┐                   ┌─────────────┐
│   BOM       │                   │ 采购申请     │  (要买多少、发给谁)
│ (型号→物料) │                   │(PurchaseReq)│
└──────┬──────┘                   └───────┬──────┘
       │                                  │
       │ 引用                              │ 审核通过后做入库
       ▼                                  ▼
┌─────────────┐                   ┌─────────────┐
│   物料      │ ◄─────────────────│ 采购入库     │  (入库后增加物料库存)
│ (Material)  │   更新库存         │(PurchaseIn) │
└─────────────┘                   └─────────────┘
```

- **物料**：基础数据，有分类、单位、价格、默认供应商、库存等。
- **订单**：包含客户、型号数量；保存后系统按 BOM 算出「订单物料需求」，缺料时自动生成「采购申请」。
- **订单物料**：某订单对某物料的需求（数量、预估金额、采购/库存状态）。
- **采购申请**：由系统根据订单物料缺料自动生成，审核通过后可做采购入库。
- **采购入库**：选择采购申请或直接选物料做入库，入库后增加物料库存，并回写申请/订单物料状态。

## 二、数据表与含义

| 模块       | 表名                     | 含义 |
|------------|--------------------------|------|
| 物料       | fa_mes_material          | 物料主数据（分类、单位、价格、库存等） |
| 物料分类   | fa_mes_material_category | 物料分类（面料、五金等） |
| 订单       | fa_mes_order             | 销售/生产订单 |
| 订单型号   | fa_mes_order_model       | 订单包含哪些产品型号、数量 |
| 订单物料   | fa_mes_order_material    | 订单需要的物料及数量、预估金额、采购/库存状态 |
| BOM        | fa_mes_bom / fa_mes_bom_item | 型号→物料用量、损耗、供应商 |
| 采购申请   | fa_mes_purchase_request  | 采购申请单（关联订单物料，审核后可入库） |
| 采购入库   | fa_mes_purchase_in       | 当前使用的入库单（一单一条物料） |

## 三、操作流程（建议顺序）

### 1. 维护基础数据（先做）

1. **物料分类**（MES → 物料分类）  
   - 新增/编辑分类（名称、编码、排序、状态）。  
   - 物料会按分类筛选展示。

2. **物料**（MES → 物料管理）  
   - 添加物料：选**分类**，填名称、编码、单位、当前价格、默认供应商、最低库存等。  
   - 后续 BOM、订单需求、采购都会用到这些物料。

3. **供应商**（MES → 供应商管理）  
   - 维护供应商信息。  
   - 物料可设「默认供应商」，订单物料/采购申请会带出该供应商。

4. **产品与 BOM**（MES → 产品管理、BOM 管理）  
   - 产品型号在「产品管理」维护。  
   - 在「BOM 管理」里为型号配置：用哪些物料、用量、损耗率、可选供应商。  
   - 订单的物料需求 = 订单各型号数量 × BOM 用量 × (1 + 损耗率)。

### 2. 订单 → 自动出「订单物料」与「采购申请」

1. **新建/编辑订单**（MES → 订单管理）  
   - 选客户、交货期，在「型号」里选产品型号及数量，保存。

2. **系统自动执行**（保存时）：  
   - 按订单型号数量 + BOM 计算物料需求，写入 **订单物料**（mes_order_material）。  
   - 对每条订单物料：若 **当前库存 < 需求量**，则自动生成一条 **采购申请**（mes_purchase_request），并标记订单物料为「已下单」等状态。

3. **查看/重算订单物料**  
   - 订单列表点某订单的「**物料**」按钮 → 进入「订单物料清单」。  
   - 可看：物料、需求量、预估金额、供应商、缺料数、采购状态、库存状态。  
   - 点「**刷新**」可强制按 BOM 重新计算并覆盖当前订单物料。

### 3. 采购申请审核

1. **采购申请列表**（MES → 采购管理 → 采购申请）  
   - 列表里是系统根据订单缺料生成的申请（待审核 / 已审核 / 已完成等）。

2. **审核**  
   - 选择申请记录，进行「审核通过」或「驳回」。  
   - 通过后：对应订单物料的「采购状态」会更新为已下单，便于后续做入库。

### 4. 采购入库（增加库存）

1. **采购入库列表**（MES → 采购管理 → 采购入库）  
   - 查看已有入库单。

2. **添加入库单**  
   - 可选「采购申请」带出物料、供应商；或直接选物料、供应商，填入库数量等。  
   - 保存后：  
     - 对应**物料库存**增加；  
     - 若关联了采购申请，该申请会标记为已完成，对应**订单物料**的采购状态会更新为已到货等。

3. **编辑/确认**  
   - 根据需要可编辑未确认的入库单；确认后一般视为正式入库。

---

## 四、状态含义（便于你排查）

- **订单物料**  
  - 采购状态：0 待采购、1 已下单、2 已到货等。  
  - 库存状态：0 待准备、1 已备料等。  

- **采购申请**  
  - 0 待审核、1 已审核（可入库）、2 已完成、3 驳回等。  

- **采购入库**  
  - 未确认 / 已确认等（以当前代码和页面为准）。

## 五、小结：你该怎么操作

| 你要做的事           | 在哪里操作                         |
|----------------------|------------------------------------|
| 维护物料及分类       | 物料分类 + 物料管理                |
| 维护供应商           | 供应商管理                        |
| 配置「型号用哪些料」  | BOM 管理（先有产品型号和物料）     |
| 下订单并出物料需求   | 订单管理 → 添加/编辑订单（保存即算） |
| 看某订单要哪些料     | 订单管理 → 该订单点「物料」        |
| 重新按 BOM 算需求    | 订单物料清单页点「刷新」           |
| 处理「要采购」的申请 | 采购管理 → 采购申请 → 审核        |
| 采购到货、增加库存   | 采购管理 → 采购入库 → 添加入库单   |

整体顺序：**物料与分类 → 供应商 → BOM → 订单 → 订单物料（自动）→ 采购申请（自动）→ 审核申请 → 采购入库**。按这个顺序操作即可把物料、采购、订单串起来用。
