# 租户自助购买功能使用说明

## 功能概述

租户自助购买功能允许用户在线选择套餐、填写信息并完成支付，系统自动创建租户账号并分配权限。

---

## 支持的支付方式

系统支持以下5种支付方式（需在后台支付配置中启用）：

1. **官方支付宝** - 支付宝扫码支付
2. **官方微信支付** - 微信扫码支付
3. **虎皮椒-支付宝** - 虎皮椒聚合支付（支付宝）
4. **虎皮椒-微信** - 虎皮椒聚合支付（微信）
5. **易支付(8-pay)** - 第三方聚合支付

---

## 完整购买流程

### 步骤1：设置套餐价格

**后台操作**：
1. 登录后台（平台超管）
2. 进入 **租户套餐** → **添加套餐** 或 **编辑套餐**
3. 填写套餐信息：
   - 套餐名称：如"基础版"、"标准版"
   - 管理员数：最大管理员数量
   - 用户数：最大用户数量
   - 有效天数：如365（留空表示永久）
   - **价格**：套餐价格（元）✨ 新增字段
   - 排序：显示顺序

### 步骤2：配置支付网关

**后台操作**：
1. 进入 **支付管理** → **支付配置**
2. 添加支付网关：
   - 官方支付宝：填写APPID、私钥等
   - 官方微信：填写APPID、密钥等
   - 虎皮椒：填写API地址、APPID、密钥
   - 易支付：填写网关地址、PID、密钥
3. 启用需要的支付方式

### 步骤3：用户购买

**用户访问**：`http://你的域名/purchase`

**购买流程**：
1. **选择套餐**：查看套餐列表和价格
2. **填写信息**：
   - 企业信息：企业名称、联系人、电话、邮箱
   - 绑定域名：填写访问域名
   - 管理员账号：设置登录账号和密码
3. **选择支付方式**：从启用的支付方式中选择
4. **发起支付**：系统创建订单并跳转支付页面
5. **支付完成**：自动创建租户和管理员账号

### 步骤4：支付回调

**自动处理**：
- 支付成功后，系统自动：
  1. 更新订单状态为"已支付"
  2. 创建租户记录
  3. 创建管理员账号
  4. 分配套餐默认角色和权限
  5. 生成登录信息

## API接口说明

### 1. 获取套餐列表
```
GET /api/tenant_purchase/package_list
```
返回所有可用套餐及功能列表

### 2. 创建订单
```
POST /api/tenant_purchase/create_order
```
参数：
- `package_id` - 套餐ID
- `company_name` - 企业名称
- `contact_name` - 联系人
- `contact_phone` - 联系电话
- `contact_email` - 联系邮箱
- `domain` - 绑定域名
- `login_account` - 登录账号
- `login_password` - 登录密码

### 3. 获取支付方式
```
GET /api/tenant_purchase/payment_methods
```
返回已启用的平台支付网关列表

### 4. 发起支付
```
POST /api/tenant_purchase/pay
```
参数：
- `order_no` - 订单号
- `gateway_id` - 支付网关ID

### 5. 支付同步回调
```
GET /api/tenant_purchase/return?order_no=xxx
```
支付完成后的跳转页面

### 6. 支付异步回调
```
POST /api/tenant_purchase/notify
```
支付平台异步通知接口

### 7. 查询订单状态
```
GET /api/tenant_purchase/order_status?order_no=xxx
```
返回订单状态及租户信息

## 注意事项

### 1. 支付回调地址
确保支付平台的回调地址配置为：
- 异步通知：`http://你的域名/api/tenant_purchase/notify`
- 同步跳转：`http://你的域名/api/tenant_purchase/return`

### 2. 域名唯一性
系统会检查域名的唯一性，避免重复注册。

### 3. 账号安全
- 密码使用 BCrypt 加密存储
- 登录账号不能重复
- 建议用户使用强密码

### 4. 权限分配
- 新租户自动获得套餐对应的默认角色
- 权限根据套餐功能配置自动生成

### 5. 订单管理
- 所有订单在后台 **租户订单** 中可查看
- 支持订单搜索和状态筛选
- 待支付订单可以取消

## 常见问题

### Q1: 支付后没有自动创建租户？
A: 检查支付回调是否成功，查看 **支付管理** → **回调日志**。

### Q2: 如何测试购买流程？
A: 可以将套餐价格设置为0.01元进行小额测试。

### Q3: 支持批量购买吗？
A: 当前版本仅支持单次购买，续费需在后台创建续费订单。

### Q4: 如何自定义购买页面？
A: 修改 `app/index/view/purchase/` 下的HTML文件。

### Q5: 支付失败订单如何处理？
A: 可在后台手动支付或取消订单重新购买。
