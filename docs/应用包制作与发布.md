# 应用包制作与发布

基础框架开源发布，业务应用（MES、CRM、AI 等）**单独打包**，用户通过后台「应用中心 → 上传应用包」安装。

---

## 一、zip 包结构

```
应用根目录/
├── app.json          # 必填，安装清单
├── app/              # 合并到项目 app/
│   └── admin/
│       ├── controller/
│       │   └── mes/  # 或 crm/、ai/、equipment/ 等
│       └── ...
├── database/         # 合并到项目 database/
│   ├── migrate_xxx.sql
│   └── seed_xxx_menu.sql
└── public/           # 可选，静态资源
```

- zip 解压后**必须有一层根目录**，根目录下放 `app.json`。
- 只允许合并到 `app`、`public`、`database` 三个目录，禁止覆盖其它路径。

---

## 二、app.json 说明

| 字段 | 必填 | 说明 |
|------|------|------|
| key | 是 | 应用唯一标识，如 mes、crm、ai |
| sql_files | 是 | 要执行的 SQL 文件名数组，路径相对 database/，如 `["migrate_add_mes_tables.sql","seed_mes_menu.sql"]` |
| title | 否 | 显示名称，用于应用中心列表；缺省用 key |
| description | 否 | 简介 |
| auth_prefix | 否 | 菜单权限前缀，与 fa_auth_rule.name 一致，如 mes、crm；缺省用 key |
| check_table | 否 | 用于判断是否已安装的表名（无前缀），如 mes_product |

示例（MES）：

```json
{
  "key": "mes",
  "title": "MES 制造执行系统",
  "description": "订单、产品、BOM、工序、报工、计划、库存、质检、工资、发货、看板",
  "auth_prefix": "mes",
  "check_table": "mes_product",
  "sql_files": [
    "migrate_add_mes_tables.sql",
    "migrate_add_mes_extended_tables.sql",
    "migrate_add_mes_complete_supply_chain.sql",
    "seed_mes_menu.sql"
  ]
}
```

---

## 三、SQL 与表前缀

- 迁移/菜单 SQL 中表名使用 **fa_**，上传安装时框架会按当前库配置替换为实际前缀。
- `runSqlFile` 会做：`fa_` → 配置前缀、`fa_auth_rule` → 前缀+auth_rule、`fa_config` → 前缀+config。

---

## 四、路由

- 应用包可在 `app/admin/route/` 下带独立路由文件（如 mes.php、crm.php）。
- 基础框架的 `route/app.php` 通过 `is_file(__DIR__ . '/mes.php')` 等方式按需加载，应用包合并后即可生效。

---

## 五、打包脚本与输出目录

各应用使用 **build/** 下脚本打包，产物统一在 **build/output/**：

| 脚本 | 中间目录 | 产出 zip | 安装后文件位置 |
|------|----------|----------|----------------|
| php build/pack_base.php [版本] | build/output/thinkmes-base/ | **dist/thinkmes-base-1.0.zip** | 解压到项目根目录，访问 /install 分步安装 |
| php build/pack_mes.php [版本] | build/output/thinkmes-mes/ | **dist/thinkmes-mes-1.0.zip** | 应用中心上传 → 合并到 **app/admin/controller/mes**、**app/admin/model/mes**、**app/admin/view/mes**、**database/**、**public/** |
| php build/pack_crm.php [版本] | build/output/thinkmes-crm/ | **dist/thinkmes-crm-1.0.zip** | 应用中心上传 → 合并到 **app/admin/controller/crm**、**app/admin/model/crm**、**app/admin/view/crm**、**database/**、**public/** |
| php build/pack_ai.php [版本] | build/output/thinkmes-ai/ | **dist/thinkmes-ai-1.0.zip** | 应用中心上传 → 合并到 **app/admin/controller/ai**、**app/admin/view/ai**、**database/**、**public/** |
| php build/pack_payment.php [版本] | build/output/thinkmes-payment/ | **dist/thinkmes-payment-1.0.zip** | 应用中心上传 → 合并到 **app/admin/controller/payment**、**app/admin/view/payment**、**database/**、**public/** |
| php build/pack_equipment.php [版本] | build/output/thinkmes-equipment/ | **dist/thinkmes-equipment-1.0.zip** | 应用中心上传 → 合并到 **app/admin/controller/equipment**、**app/admin/model/equipment**、**app/admin/view/equipment**、**database/** |
| php build/pack_hr.php [版本] | build/output/thinkmes-hr/ | **dist/thinkmes-hr-1.0.zip** | 应用中心上传 → 合并到 **app/admin/controller/hr**、**app/admin/model/hr**、**app/admin/view/hr**、**database/** |
| php build/pack_finance.php [版本] | build/output/thinkmes-finance/ | **dist/thinkmes-finance-1.0.zip** | 应用中心上传 → 合并到 **app/admin/controller/finance**、**app/admin/model/finance**、**app/admin/view/finance**、**database/** |

**说明**：
- **中间目录**（build/output/thinkmes-xxx/）：打包过程临时目录，用于生成 zip。
- **产出 zip**（dist/thinkmes-xxx-1.0.zip）：最终发布包，提供给用户或上传到应用中心。
- **安装后位置**：应用中心上传安装时，会将 zip 解压并**合并到项目根目录的正常目录**（如 `/www/wwwroot/thinkmes/app/admin/controller/crm`），不会放到 build/output。

---

## 六、发布清单（每应用）

1. 按上述结构打 zip，根目录含 `app.json`。
2. 确保 `sql_files` 中列出的文件都在 zip 的 `database/` 下。
3. 提供简短安装说明：登录超管 → 应用中心 → 上传应用包 → 选择 zip。

基础框架不内置任何应用，各应用单独发布、按需安装即可。打包后 zip 放在 **dist/**，可直接提供给用户或上传到应用中心安装。安装时文件会合并到项目根目录的正常目录（app/、public/、database/），不会放到 build/output。
