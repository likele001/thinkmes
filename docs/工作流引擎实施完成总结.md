## 使用指南

### 快速开始

1. **执行数据库迁移**（已完成）
   ```bash
   mysql -u root -p thinkmes < database/migrate_workflow_engine.sql
   mysql -u root -p thinkmes < database/workflow_menu.sql
   ```

2. **配置模块**
   - 进入后台：工作流 -> 模块配置
   - 启用需要的模块（如：订单审批）
   - 设置默认工作流模板

3. **设计流程**
   - 进入：工作流 -> 流程定义
   - 点击"设计流程"进入可视化设计器
   - 拖拽节点并配置属性

4. **业务集成**
   - 参考 `docs/工作流引擎使用指南.md`
   - 在业务代码中调用 WorkflowService

5. **审批测试**
   - 提交审批数据
   - 进入：审批中心 -> 待我审批
   - 进行审批操作

### 订单审批示例

```php
// 订单提交时启动工作流
$workflowModule = WorkflowModule::getByModuleCode('order', $tenantId);

if ($workflowModule && $workflowModule->is_enabled) {
    $workflowService = new WorkflowService();

    $instanceId = $workflowService->startWorkflow(
        $workflowModule->default_workflow_id,
        'order',
        $orderId,
        '订单号：' . $order['order_no'],
        $userId,
        $tenantId
    );

    // 更新订单状态
    $order->workflow_instance_id = $instanceId;
    $order->workflow_status = 'pending';
    $order->save();
}
```

## 扩展功能

### 1. 定时任务（超时检查）

在 `application/command.php` 中添加：

```php
return [
    'workflow' => 'app\common\command\WorkflowTimeout',
];
```

创建定时任务文件 `app/common/command/WorkflowTimeout.php`：

```php
<?php
namespace app\common\command;

use app\common\service\WorkflowTimeoutService;
use think\console\Command;
use think\console\Input;
use think\console\Output;

class WorkflowTimeout extends Command
{
    protected function configure()
    {
        $this->setName('workflow:timeout')->setDescription('检查工作流超时');
    }

    protected function execute(Input $input, Output $output)
    {
        $service = new WorkflowTimeoutService();
        $stats = $service->checkTimeout();
        $output->writeln('超时检查完成：' . json_encode($stats));
    }
}
```

配置 Crontab：
```bash
# 每小时检查一次
0 * * * * php think workflow:timeout
```

{
    public function fire(Job $job, $data)
    {
