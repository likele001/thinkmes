# 自媒体工作流 - AI 模型推荐与对接要点

面向多用户、轻量化、低成本的 KeleAdmin 自媒体应用，推荐以下**免费优先 + 低价备选**模型，便于在后台「自媒体配置」中选用并接入 AI 服务层。

---

## 一、文本生成（文案 / 选题 / 复盘报告）

| 类型 | 模型 | 说明 | 对接要点 |
|------|------|------|----------|
| 免费 | **豆包 API** | 字节自研，免费额度足，中文场景贴合 | 开放平台申请 API Key，兼容 OpenAI 风格或官方 HTTP 接口 |
| 免费 | **智谱 ChatGLM** | 开放平台/本地部署 | open.bigmodel.cn，API Key + 模型名如 chatglm_turbo |
| 免费 | **讯飞星火** | 免费额度多，多轮编辑 | 讯飞开放平台，API Key + 接口地址，支持文案/SEO |
| 低价 | **GPT-3.5 Turbo** | 按量计费，单价低 | api.openai.com，Bearer Key，model: gpt-3.5-turbo |
| 低价 | **百度文心一言** | 月度低价套餐，中文友好 | 千帆大模型平台，API Key + 模型名 |

**服务层对接**：统一走「文本生成」配置项（provider + model + api_key + api_base），请求时根据 provider 选择对应 HTTP 客户端与参数格式。

---

## 二、图片生成（封面 / 配图 / 素材）

| 类型 | 模型 | 说明 | 对接要点 |
|------|------|------|----------|
| 免费 | **通义万相** | 阿里云，每日免费次数 | 阿里云控制台开通，API Key + 请求地址，支持多风格 |
| 免费 | **Stable Diffusion 本地** | 开源，零服务器成本 | 本地部署 WebUI/SDK，api_base 指向本机地址 |
| 免费 | **剪映 AI 配图** | 免费，风格贴合短视频 | 按剪映开放能力文档对接（若有 API） |
| 低价 | **通义万相按量** | 超出免费后按张计费 | 同通义万相，计费模式切换 |
| 低价 | **MidJourney** | 订阅制，高质量 | 多通过第三方 API 或机器人对接 |

**服务层对接**：使用「图片生成」配置项，根据 provider 调用对应图生 API（prompt + 尺寸等），结果 URL 写入素材或封面字段。

---

## 三、视频生成（短视频 / 片头）

| 类型 | 模型 | 说明 | 对接要点 |
|------|------|------|----------|
| 免费 | **VideoCrafter 本地** | 开源，15～60 秒短视频 | 本地部署，api_base 指向本地服务 |
| 免费 | **Runway ML 免费版** | 免费额度，文生视频/风格转换 | 开放 API 注册，按文档传脚本/图 |
| 免费 | **讯飞听见视频** | 免费额度，脚本/音频转视频 | 讯飞开放平台，视频生成类 API |
| 低价 | **Pika Labs** | 按时长计费 | 按官方 API 文档对接 |
| 低价 | **阿里云视频生成** | 按量计费 | 阿里云智能媒体服务相关 API |

**服务层对接**：使用「视频生成」配置项，根据 provider 调用对应接口（文本/脚本或图生视频），返回视频 URL 或任务 ID 轮询结果。

---

## 四、内容安全（合规检测）

可与文本生成共用同一供应商（如豆包、文心、通义均提供内容安全接口），或单独配置一条「内容安全」模型，使用各厂商的**内容审核/合规 API**（如阿里云内容安全、腾讯云天御等），对接方式为：API Key + 请求地址，传入待检文本，返回结果与建议。

---

## 五、在应用中的使用方式

1. **后台配置**：管理员在「自媒体工作流 → 自媒体配置」中按用途选择供应商、填写模型名、API Key、API 地址（可选）。
2. **服务层**：业务代码读取 `fa_wemedia_config` 中 `tenant_id=0` 的对应 key（如 ai_text_provider、ai_text_api_key…），根据 provider 分支调用不同厂商 API。
3. **扩展**：新增厂商时在 `WemediaConfigModel::getAiProviderOptions()` 中增加选项，在服务层增加对应分支即可。

如需我补充**某一具体厂商的请求示例（URL、请求体、响应解析）**，可指定厂商名称，便于直接写出可用的调用代码片段。
