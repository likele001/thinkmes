# 工作流引擎设计方案

## 一、系统架构

### 1.1 整体架构
```
┌─────────────────────────────────────────────────────────┐
│                      业务模块层                           │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐   │
│  │订单管理 │  │工资管理 │  │采购管理 │  │ 其他模块 │   │
│  └────┬────┘  └────┬────┘  └────┬────┘  └────┬────┘   │
│       │            │            │            │          │
│       └────────────┴────────────┴────────────┘          │
│                    │                                     │
│            ┌───────▼────────┐                          │
│            │  工作流中间件   │                          │
│            │  (可选启用)     │                          │
│            └───────┬────────┘                          │
└────────────────────┼─────────────────────────────────────┘
                     │
         ┌───────────▼────────────┐
         │    工作流引擎核心      │
         │  ├── 流程设计器        │
         │  ├── 流程模板管理      │
         │  ├── 审批执行引擎      │
         │  └── 消息通知          │
         └────────────────────────┘
```

### 1.2 核心设计理念

1. **模块化设计**：工作流作为独立模块，业务模块可选启用
2. **低侵入集成**：业务表只需添加2个字段
3. **可视化配置**：拖拽式流程设计器
4. **灵活的审批人**：支持角色、部门、指定人员等多种方式
5. **完整的追溯**：所有审批操作可追溯

## 二、数据库设计

### 2.1 核心表结构

#### 1. 工作流模块配置表 (workflow_module)
```sql
CREATE TABLE `workflow_module` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `module_code` varchar(50) NOT NULL COMMENT '模块代码：order/salary/purchase等',
  `module_name` varchar(100) NOT NULL COMMENT '模块名称',
  `table_name` varchar(100) NOT NULL COMMENT '关联业务表名',
  `title_field` varchar(50) NOT NULL COMMENT '标题字段：order_no',
  `is_enabled` tinyint(1) DEFAULT 0 COMMENT '是否启用工作流：0否1是',
  `default_workflow_id` int(11) DEFAULT NULL COMMENT '默认工作流模板ID',
  `tenant_id` int(11) NOT NULL COMMENT '租户ID',
  `create_time` datetime DEFAULT NULL,
  `update_time` datetime DEFAULT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_module_tenant` (`module_code`,`tenant_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='工作流模块配置表';
```

#### 2. 工作流定义表 (workflow_definition)
```sql
CREATE TABLE `workflow_definition` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `name` varchar(100) NOT NULL COMMENT '流程名称',
  `code` varchar(50) NOT NULL COMMENT '流程代码',
  `module_code` varchar(50) NOT NULL COMMENT '所属模块',
  `description` text COMMENT '流程描述',
  `form_config` text COMMENT '表单配置JSON',
  `is_default` tinyint(1) DEFAULT 0 COMMENT '是否默认流程',
  `status` tinyint(1) DEFAULT 1 COMMENT '状态：0禁用1启用',
  `tenant_id` int(11) NOT NULL,
  `create_by` int(11) DEFAULT NULL,
  `create_time` datetime DEFAULT NULL,
  `update_time` datetime DEFAULT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_code` (`code`,`tenant_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='工作流定义表';
```

#### 3. 流程节点表 (workflow_node)
```sql
CREATE TABLE `workflow_node` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `workflow_id` int(11) NOT NULL COMMENT '工作流ID',
  `node_code` varchar(50) NOT NULL COMMENT '节点代码',
  `node_name` varchar(100) NOT NULL COMMENT '节点名称',
  `node_type` varchar(20) NOT NULL COMMENT '节点类型：start/approval/copy/condition/end',
  `approval_type` varchar(20) DEFAULT NULL COMMENT '审批类型：and(会签)/or(或签)',
  `position_x` int(11) DEFAULT NULL COMMENT '画布X坐标',
  `position_y` int(11) DEFAULT NULL COMMENT '画布Y坐标',
  `config` text COMMENT '节点配置JSON',
  `sort` int(11) DEFAULT 0 COMMENT '排序',
  `create_time` datetime DEFAULT NULL,
  PRIMARY KEY (`id`),
  KEY `idx_workflow_id` (`workflow_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='流程节点表';
```

#### 4. 节点审批人配置表 (workflow_node_approver)
```sql
CREATE TABLE `workflow_node_approver` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `node_id` int(11) NOT NULL COMMENT '节点ID',
  `approver_type` varchar(20) NOT NULL COMMENT '审批人类型：role/user/department/superior/initiator',
  `approver_value` varchar(500) DEFAULT NULL COMMENT '审批人值（角色ID/用户ID/部门ID等）',
  `sort` int(11) DEFAULT 0,
  `create_time` datetime DEFAULT NULL,
  PRIMARY KEY (`id`),
  KEY `idx_node_id` (`node_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='节点审批人配置表';
```

#### 5. 节点流转关系表 (workflow_edge)
```sql
CREATE TABLE `workflow_edge` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `workflow_id` int(11) NOT NULL,
  `from_node` varchar(50) NOT NULL COMMENT '源节点',
  `to_node` varchar(50) NOT NULL COMMENT '目标节点',
  `condition` text COMMENT '流转条件JSON',
  `create_time` datetime DEFAULT NULL,
  PRIMARY KEY (`id`),
  KEY `idx_workflow_id` (`workflow_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='节点流转关系表';
```

#### 6. 流程实例表 (workflow_instance)
```sql
CREATE TABLE `workflow_instance` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `instance_no` varchar(50) NOT NULL COMMENT '实例编号',
  `workflow_id` int(11) NOT NULL COMMENT '工作流定义ID',
  `module_code` varchar(50) NOT NULL COMMENT '模块代码',
  `business_id` int(11) NOT NULL COMMENT '业务数据ID',
  `business_title` varchar(255) DEFAULT NULL COMMENT '业务标题',
  `current_node` varchar(50) DEFAULT NULL COMMENT '当前节点',
  `status` varchar(20) DEFAULT 'running' COMMENT '状态：running/completed/cancelled',
  `initiator_id` int(11) NOT NULL COMMENT '发起人ID',
  `tenant_id` int(11) NOT NULL,
  `create_time` datetime DEFAULT NULL,
  `complete_time` datetime DEFAULT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_instance_no` (`instance_no`),
  KEY `idx_business` (`module_code`,`business_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='流程实例表';
```

#### 7. 审批记录表 (workflow_approval_record)
```sql
CREATE TABLE `workflow_approval_record` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `instance_id` int(11) NOT NULL COMMENT '流程实例ID',
  `node_id` int(11) NOT NULL COMMENT '节点ID',
  `node_code` varchar(50) NOT NULL COMMENT '节点代码',
  `node_name` varchar(100) NOT NULL COMMENT '节点名称',
  `approver_id` int(11) NOT NULL COMMENT '审批人ID',
  `approver_name` varchar(100) DEFAULT NULL COMMENT '审批人姓名',
  `action` varchar(20) NOT NULL COMMENT '操作：approve/reject/transfer/comment',
  `comment` text COMMENT '审批意见',
  `attachment` varchar(500) DEFAULT NULL COMMENT '附件',
  `status` varchar(20) DEFAULT 'pending' COMMENT '状态：pending/approved/rejected',
  `action_time` datetime DEFAULT NULL COMMENT '操作时间',
  `create_time` datetime DEFAULT NULL,
  PRIMARY KEY (`id`),
  KEY `idx_instance_id` (`instance_id`),
  KEY `idx_approver_id` (`approver_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='审批记录表';
```

### 2.2 业务表集成字段

所有需要启用工作流的业务表都需要添加以下字段：

```sql
-- 业务表添加字段示例（以订单表为例）

ADD COLUMN `workflow_instance_id` int(11) DEFAULT NULL COMMENT '工作流实例ID',

ADD INDEX `idx_workflow_instance` (`workflow_instance_id`);
```

## 四、节点类型说明

### 4.1 节点类型

#### 1. 开始节点 (start)
- 流程的起点
- 自动流转到下一节点

#### 2. 审批节点 (approval)
- 需要人工审批
- 支持会签（所有审批人都通过）
- 支持或签（任一审批人通过即可）

#### 3. 抄送节点 (copy)
- 通知相关人员
- 不影响流程流转

#### 4. 条件节点 (condition)
- 根据条件判断流转路径
- 支持多条件判断

#### 5. 结束节点 (end)
- 流程终止
- 标记流程状态

### 4.2 审批人类型

1. **role** - 指定角色
   - 示例：财务经理

2. **user** - 指定人员
   - 示例：张三

3. **department** - 部门负责人
   - 示例：财务部负责人

4. **superior** - 直属上级
   - 发起人的直属上级

5. **initiator** - 发起人本人
   - 用于回退等场景

6. **custom** - 自定义
   - 通过自定义逻辑确定审批人

## 五、业务集成示例

### 5.1 订单审批集成

#### 1. 启用工作流
```php
// 检查订单模块是否启用工作流
$workflowModule = WorkflowModule::where('module_code', 'order')
    ->where('is_enabled', 1)
    ->find();

if ($workflowModule) {
    // 创建订单时启动工作流
    $workflowService = new WorkflowService();
    $instanceId = $workflowService->startWorkflow(
        $workflowModule->default_workflow_id,
        'order',
        $orderId,
        '订单号：' . $order['order_no'],
        $userId
    );
    
    // 更新订单状态
    $order->workflow_instance_id = $instanceId;
    $order->workflow_status = 'pending';
    $order->save();
}
```

#### 2. 订单详情页集成
```php
// 在订单详情页显示审批状态和操作按钮
if ($order->workflow_instance_id) {
    // 显示当前审批节点
    // 显示审批进度
    // 如果是待审批状态，显示审批/拒绝按钮
}
```

## 六、API接口设计

### 6.1 模块管理接口

```php
// 获取已启用工作流的模块列表
GET /admin/workflow/modules

// 启用/禁用模块工作流
POST /admin/workflow/module/toggle
{
    "module_code": "order",
    "is_enabled": 1,
    "default_workflow_id": 1
}
```

### 6.2 流程设计接口

```php
// 保存流程设计
POST /admin/workflow/design/save
{
    "workflow_id": 1,
    "nodes": [...],
    "edges": [...]
}

// 获取流程详情
GET /admin/workflow/design/detail?id=1
```

### 6.3 审批接口

```php
// 提交审批
POST /admin/workflow/submit
{
    "workflow_id": 1,
    "module_code": "order",
    "business_id": 123,
    "comment": "请审批"
}

// 审批操作
POST /admin/workflow/approve
{
    "record_id": 1,
    "action": "approve", // approve/reject/transfer
    "comment": "同意"
}
```
