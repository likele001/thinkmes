# 前端技术栈与约定

## 前端 UI：Pear Admin

**约定：本项目前端 UI 统一使用 Pear Admin，后续所有前端页面与组件均按此规范。**

- 后台管理（admin）、用户中心（index）等前端界面，均基于 **Pear Admin** 的布局、组件与风格开发。
- 不再使用 AdminLTE 或其他后台模板作为主 UI 框架。
- 现有实现参考：
  - 布局：`app/admin/view/layout/default.html`（`.pear-admin-wrap`、`.pear-header`、`.pear-side`、`.pear-main`、`.pear-tabs`、`.pear-content`）
  - 样式：`public/assets/css/pear-admin-theme.css`（Pear Admin Layui 风格）
  - 配合 Layui 图标与组件（如 `layui-icon-*`）

## 开发时注意

- 新页面保持与现有 Pear Admin 主题一致（类名、配色、图标）。
- 表格、表单、按钮等尽量复用 Pear Admin / Layui 组件，或使用与 `pear-admin-theme.css` 兼容的样式类。

## 相关规则

- Cursor 规则：`.cursor/rules/frontend-ui-pear-admin.mdc`（AI 与编辑器会据此优先使用 Pear Admin）
