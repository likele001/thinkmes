## 快速测试流程

### 步骤1：创建工作流定义

1. 访问：`/admin/workflow/add`
2. 填写表单：
   - **流程名称**：`测试订单审批`
   - **流程代码**：`test_order_approval`
   - **所属模块**：`订单审批`
   - **流程描述**：`用于测试的订单审批流程`
   - **状态**：`启用`
3. 点击"保存"
4. ✅ 应该显示"创建成功"并返回列表页

### 步骤2：设计流程

1. 在工作流列表中，找到刚创建的流程
2. 点击"设计"按钮
3. 在流程设计器中：

   **拖拽节点到画布：**
   - 从左侧工具栏拖拽"开始节点"到画布
   - 拖拽"审批节点"到画布（可以拖多个）
   - 拖拽"结束节点"到画布

   **配置审批节点：**
   - 点击审批节点的"配置"按钮
   - 设置节点名称：如"经理审批"
   - 选择审批类型：或签（任一人通过即可）
   - 选择审批人类型：指定用户
   - 点击"保存"

   **连接节点：**
   - 按住 Ctrl 键
   - 依次点击：开始节点 → 审批节点 → 结束节点
   - 形成完整的流程连线

4. 点击右上角"保存"按钮
5. ✅ 应该显示"保存成功"

### 步骤3：配置模块

1. 访问：`/admin/workflow/moduleConfig`
2. 找到"订单审批"模块
3. 点击"启用"按钮
4. ✅ 应该显示"操作成功"，状态变为"已启用"

### 步骤4：测试业务集成

创建一个测试文件 `test_workflow.php`：

```php
<?php
require __DIR__ . '/vendor/autoload.php';

// 初始化应用
$app = new think\App();
$app->initialize();

// 引入服务
use app\common\service\WorkflowService;
use app\admin\model\WorkflowModule;

try {
    // 获取订单模块配置
    $workflowModule = WorkflowModule::getByModuleCode('order', 1);

    if (!$workflowModule || !$workflowModule->is_enabled) {
        echo "❌ 模块未启用工作流\n";
        exit;
    }

    echo "✅ 模块已启用工作流\n";
    echo "默认流程ID：{$workflowModule->default_workflow_id}\n";

    // 启动测试工作流
    $workflowService = new WorkflowService();
    $instanceId = $workflowService->startWorkflow(
        $workflowModule->default_workflow_id,
        'order',
        999, // 测试业务ID
        '测试订单：TEST001',
        1,   // 发起人ID
        1    // 租户ID
    );

    echo "✅ 工作流启动成功！\n";
    echo "流程实例ID：{$instanceId}\n";

    // 查看流程状态
    $instance = \app\admin\model\WorkflowInstance::find($instanceId);
    echo "当前节点：{$instance->current_node}\n";
    echo "流程状态：{$instance->status}\n";

} catch (\Exception $e) {
    echo "❌ 错误：" . $e->getMessage() . "\n";
}
```

运行测试：
```bash
php test_workflow.php
```

**预期输出：**
```
✅ 模块已启用工作流
默认流程ID：1
✅ 工作流启动成功！
流程实例ID：1
当前节点：manager_approval
流程状态：running
```

## 常见问题排查

### 问题1：找不到"工作流"菜单

**原因：** 菜单未导入或权限未分配

**解决方案：**
```sql
-- 检查菜单是否存在
SELECT * FROM fa_auth_rule WHERE name LIKE 'workflow%';

-- 如果不存在，重新导入菜单
mysql -u root -p thinkmes < database/workflow_menu.sql;

-- 清除缓存
rm -rf runtime/cache/*
```

### 问题2：保存流程时提示"保存失败"

**原因：** 节点数据格式不正确

**解决方案：**
1. 打开浏览器控制台（F12）
2. 查看Network标签页的请求详情
3. 检查发送的nodes和edges数据格式
4. 确保每个节点都有：node_code、node_name、node_type、position_x、position_y

### 问题3：启动工作流时提示"该业务已启动工作流"

**原因：** 该业务ID已经有运行中的流程

**解决方案：**
```sql
-- 查看现有流程实例
SELECT * FROM fa_workflow_instance
WHERE module_code = 'order' AND business_id = 999;

-- 删除测试数据
DELETE FROM fa_workflow_instance WHERE business_id = 999;
DELETE FROM fa_workflow_approval_record WHERE business_id = 999;
```

### 问题4：没有收到审批通知

**原因：** 消息通知服务未配置

**解决方案：**
1. 检查是否启用了消息通知
2. 确认 `fa_message` 表存在
3. 查看日志文件：`runtime/log/`

### 问题5：流程设计器节点无法拖拽

**原因：** JavaScript冲突或CSS问题

**解决方案：**
1. 清除浏览器缓存
2. 确保jQuery已加载
3. 检查控制台是否有JavaScript错误
4. 使用Chrome浏览器测试

## 性能测试

### 批量测试

```php
<?php
// 批量创建100个测试工作流
use app\common\service\WorkflowService;

$workflowService = new WorkflowService();

for ($i = 1; $i <= 100; $i++) {
    try {
        $instanceId = $workflowService->startWorkflow(
            1,  // workflow_id
            'order',
            $i, // business_id
            "批量测试订单 #{$i}",
            1,  // initiator_id
            1   // tenant_id
        );
        echo "✅ 创建实例 #{$i}，ID: {$instanceId}\n";
    } catch (\Exception $e) {
        echo "❌ 实例 #{$i} 失败: " . $e->getMessage() . "\n";
    }
}

echo "\n批量测试完成！\n";
```
