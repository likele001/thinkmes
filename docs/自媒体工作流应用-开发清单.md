# 文案+短视频自媒体工作流应用 · 开发清单

> 方案来源：多用户适配·实用导向。  
> **落地说明**：本应用在 **KeleAdmin 用户中心（前端 C 端）** 开发，使用 **user** 端（如 `app/index`），**不是** admin 后台；**前端 UI 统一使用 Pear Admin**。**前端用户暂时全部权限**，不做角色/权限细分，首版不开发后台侧账号与权限管理。

---

## 一、应用总览（8 大模块，均属用户中心 user 端）

| 序号 | 应用名称       | 一句话说明                           | 优先级 |
|------|----------------|--------------------------------------|--------|
| 1    | 账号与个人设置 | 用户中心已有：登录/注册/个人资料/改密；首版不做角色与权限分配 | P0（复用已有） |
| 2    | 选题策划       | AI 选题、收藏分类、进度标记、可选共享 | P0     |
| 3    | 文案创作       | AI 文案、编辑查重、SEO/标签、可选共享 | P0     |
| 4    | 素材管理       | 分类存储、检索、AI 优化、关联作品、私有/共享 | P0     |
| 5    | 短视频辅助     | 脚本生成、字幕、裁剪转码、封面生成、可选共享 | P1     |
| 6    | 发布排期       | 关联作品、排期、AI 推荐时间、提醒、状态与可见范围 | P1     |
| 7    | 数据复盘       | 数据录入/导入、AI 分析报告、图表、个人/团队数据 | P1     |
| 8    | 合规检测       | 文案/图/视频违规检测、修改建议、检测记录（个人） | P1     |

## 前端访问地址（用户中心 C 端）

应用入口在 **index 应用**（用户中心），需**登录后**访问。假设站点域名为 `https://你的域名.com`：

| 用途 | 地址 | 说明 |
|------|------|------|
| **自媒体工作台首页** | `/index/wemedia/index` | 入口页，侧栏为各子模块 |
| 选题策划 | `/index/wemedia/topic/index` | 列表；add/edit/save/del/list、generate |
| 文案创作 | `/index/wemedia/copy/index` | 列表；add/edit/save/del/list |
| 素材管理 | `/index/wemedia/material/index` | 列表；add/edit/save/del/list、upload |
| 短视频辅助 | `/index/wemedia/video/index` | 脚本列表；add/edit/save/del/list |
| 发布排期 | `/index/wemedia/schedule/index` | 列表；add/edit/save/del/list |
| 数据复盘 | `/index/wemedia/report/index` | 列表；list/chart、save/del |

用户中心导航里「自媒体工作台」链接即指向 `/index/wemedia/index`（见 `app/index/view/layout/default.html`、`app/index/view/user/index.html`）。

## 二、各应用功能与文案（需开发项）

### 1. 账号与个人设置（用户中心已有，首版仅复用）

**定位**：本应用在 **用户中心（user）** 使用，不占用 admin。账号与登录、个人资料、修改密码等**直接复用 KeleAdmin 用户中心已有能力**。

| 功能点         | 说明与文案要点 |
|----------------|----------------|
| 登录/注册      | 复用用户中心：手机/邮箱注册登录、密码加密与重置（已有） |
| 个人资料       | 复用用户中心：个人资料、修改密码、找回密码（已有） |
| 权限（首版）   | **前端用户暂时全部权限**：所有登录用户均可使用选题、文案、素材、排期、复盘、合规检测等全部功能，不做角色分级与权限分配 |
| 角色/权限（后期） | 若后续需要多用户协作与权限管控，再扩展「角色、权限分配、操作日志」等，在用户中心或后台按需增加 |

**技术要点**：接口与页面均在 **app/index（用户中心）** 下新增，如 `index/wemedia/xxx` 或挂到现有用户中心菜单下；不占用 admin；用户身份沿用现有 C 端用户表（如 member/user 等）。

---

### 2. 选题策划

**定位**：从选题生成到进度管理，支持个人与可选团队共享。

| 功能点         | 说明与文案要点 |
|----------------|----------------|
| AI 选题生成    | 按领域关键词、平台生成多条差异化选题（方向+亮点） |
| 选题管理       | 收藏、删除、编辑、备注；状态：待创作 / 已完成 |
| 选题检索       | 关键词检索；多用户下可筛「个人选题」「共享选题」 |
| 共享与协作     | 多用户下：共享范围（全部/指定用户）、协同编辑与简单修改记录 |

**技术要点**：选题表（含创建人、共享状态、共享范围）；对接文本 AI；列表/筛选/共享接口。

---

### 3. 文案创作

**定位**：多平台文案生成、编辑、优化与查重，可关联选题与素材。

| 功能点         | 说明与文案要点 |
|----------------|----------------|
| AI 文案生成    | 选平台、关联选题、输入要点，生成标题+正文+标签，可改 |
| 文案编辑       | 富文本（换行/加粗/斜体）、插入素材库图片；多用户下可协同编辑与修改人标记 |
| 文案优化       | AI 优化语气、SEO；查重与原创度建议 |
| 文案库与排期   | 保存到「我的文案库」，按平台/选题分类，可关联发布排期；多用户下私有/共享与权限 |

**技术要点**：文案表（创建人、共享状态、共享范围、修改记录）；富文本组件；对接文本 AI、素材库、排期模块。

---

### 4. 素材管理

**定位**：统一素材库，支持分类、检索、AI 优化与关联作品，私有/共享可控。

| 功能点         | 说明与文案要点 |
|----------------|----------------|
| 分类存储       | 按类型：文案/图片/视频/音频；可自定义子分类；多用户下个人库/共享库 |
| 上传与管理     | 本地上传（可扩展 OSS），批量上传；多用户下上传时选「私有/共享」 |
| 素材优化       | 图片 AI 裁剪/压缩；音频降噪；视频格式转换等 |
| 检索与关联     | 关键词检索，按类型、时间筛选；可关联到文案、短视频脚本；共享素材权限管控 |

**技术要点**：复用 ThinkMes 附件/存储能力；素材表（类型、创建人、共享状态、共享范围）；与文案、短视频、排期关联。

---

### 5. 短视频辅助

**定位**：脚本、字幕、素材处理与封面生成，降低剪辑门槛。

| 功能点         | 说明与文案要点 |
|----------------|----------------|
| 脚本生成       | 输入主题、时长、平台，AI 生成分镜脚本，可编辑；多用户下可共享与协同编辑 |
| 字幕处理       | 上传音频/视频，AI 转字幕，可编辑与导出 |
| 素材处理       | 视频裁剪、格式转换、音频降噪（如 FFmpeg） |
| 封面生成       | 输入主题与风格，AI 生成封面图，可下载替换；多用户下封面可共享 |
| 视频素材共享   | 多用户下视频素材私有/共享与权限 |

**技术要点**：脚本表、视频素材表（创建人、共享状态）；对接文本/语音/图像 AI；FFmpeg 或云服务做转码与降噪。

---

### 6. 发布排期

**定位**：把文案/短视频与平台、时间绑定，支持提醒与可见范围。

| 功能点         | 说明与文案要点 |
|----------------|----------------|
| 排期设置       | 选择关联文案或短视频、平台、发布时间、备注 |
| AI 推荐时间    | 按平台推荐最佳发布时间 |
| 排期提醒       | 应用内提醒；多用户下可选提醒对象（如团队成员） |
| 状态与可见     | 状态：待发布 / 已发布 / 已下架；首版仅个人可见；团队可见/管理员可看全部为后期扩展 |

**技术要点**：排期表（关联作品、平台、时间、创建人、可见范围）；与文案、短视频模块关联；可选简单提醒（站内/邮件等）。

---

### 7. 数据复盘

**定位**：录入或导入数据，AI 分析与可视化，支持个人与团队数据。

| 功能点         | 说明与文案要点 |
|----------------|----------------|
| 数据录入       | 手动/批量录入作品数据；多用户下普通用户录自己的，管理员可录团队汇总 |
| AI 复盘        | 一键生成复盘报告；多用户下支持个人报告与团队汇总报告 |
| 数据可视化     | 柱状图、折线图等对比；首版仅个人数据；团队汇总/管理员查看为后期扩展 |
| 报告保存与共享 | 按时间、平台保存报告；多用户下可设个人私有/团队共享 |

**技术要点**：复盘数据表、报告表（创建人、个人/团队类型）；对接文本 AI；图表组件（如 ECharts）；权限与共享接口。

---

### 8. 合规检测

**定位**：发布前文案/图片/视频合规检测，降低违规风险。

| 功能点         | 说明与文案要点 |
|----------------|----------------|
| 内容检测       | 文案/图片/视频违规识别，标记位置并给修改建议 |
| 检测记录       | 首版仅个人查看自己的检测记录（用户中心侧）；管理员查看全部可后期扩展 |
| 违规提醒       | 应用内提醒（用户中心） |

**技术要点**：对接内容安全 API（如阿里云/腾讯云）；检测记录表（检测人、内容、结果、时间）；与文案、素材模块联动。

## 三、基础与复用（用户中心 user 端 · ThinkMes）

| 类别         | 内容 |
|--------------|------|
| **运行位置** | **KeleAdmin 用户中心（前端）**：路由与控制器在 **app/index**（user 端），**不是** app/admin；页面与菜单挂在用户中心内 |
| 前端         | **前端 UI 统一使用 Pear Admin**；复用用户中心现有前端，表格/表单/弹窗；按需引入富文本、图表、上传组件 |
| 后端         | ThinkPHP；接口写在 **index** 应用下（如 `index/wemedia/topic`、`index/wemedia/copy`）；租户/用户身份沿用现有 C 端用户体系 |
| 数据存储     | MySQL，在现有库中新增自媒体相关表；通过 `tenant_id`/创建人/共享字段区分数据；**首版前端用户全部权限，不做细粒度权限表** |
| 文件存储     | 复用现有上传与附件逻辑（用户中心或 API 已有），可选 OSS；素材与合规检测共用 |
| AI 与第三方   | 文本（豆包/ChatGLM 等）、图像（SD/通义万相等）、语音（讯飞听见等）、内容安全 API，以配置项/插件形式对接 |

## 四、开发阶段建议（与方案对应）

| 阶段     | 周期   | 重点 |
|----------|--------|------|
| 第一阶段 | 约 1 周 | 数据表设计（含多用户/共享字段）、AI 对接、各模块基础 CRUD 与列表 |
| 第二阶段 | 约 1 周 | 用户中心侧：选题、文案、素材（含共享基础）；账号复用已有，不做权限分配 |
| 第三阶段 | 约 2 周 | 短视频辅助、发布排期、数据复盘、合规检测及多用户协作完善 |
| 第四阶段 | 约 1 周 | 联调、自用/多用户模式切换、测试与文案/界面优化 |

---

## 五、不做的范围（与方案一致）

- 复杂任务/绩效/广告投放/粉丝管理
- 专业级视频剪辑（仅保留基础辅助）
- 多模型堆砌（优先轻量、低成本、易对接）
- 高并发架构（面向 2–10 人小团队与个人）

**约束**：应用全部在 **用户中心（user / app/index）** 开发，**不是** admin；**前端用户暂时全部权限**；**前端 UI 统一使用 Pear Admin**（见项目约定 `.cursor/rules/frontend-ui-pear-admin.mdc`）。
