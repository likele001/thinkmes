# 工作流审批引擎使用指南

## 📦 模块概述

全新开发的工作流审批引擎，采用钉钉/飞书风格的**线性节点配置**，支持多租户隔离、条件触发、审批人灵活指定、业务单据状态自动回写等核心能力。

---

## 🎯 核心功能

### 1. 审批流定义管理
- 创建、编辑、删除审批流
- 启用/禁用审批流状态
- 同租户内流程名称唯一性校验
- 支持按业务模块筛选

### 2. 线性节点配置
- 从上到下的线性节点列表
- 支持拖拽排序调整节点顺序
- 至少保留一个审批节点
- 固定"发起人"和"结束"占位节点

### 3. 审批人规则（4种类型）
- **管理员指定**：手动选择具体管理员
- **角色指定**：按角色分配审批权
- **部门负责人**：自动获取发起人所属部门的负责人
- **发起人自选**：提交时由发起人选择审批人

### 4. 审批方式
- **会签（countersign）**：所有审批人均须通过
- **或签（any_sign）**：任一审批人通过即可

### 5. 节点触发条件
- 支持6种比较运算符：大于、小于、等于、不等于、包含、不包含
- 支持 AND/OR 逻辑组合
- 条件不满足时自动跳过该节点

### 6. 业务模块接入
- 支持 MES、CRM、HR、财务、设备等17+业务模块
- 配置业务表名、状态字段、审批通过/拒绝值
- 审批结束后自动回写业务单据状态

### 7. 审批中心
- **待我审批**：查看和处理待审批任务
- **我已审批**：查看历史审批记录
- **我发起的**：查看我发起的审批实例
- 支持通过、拒绝、转交、撤回操作

### 8. 多租户隔离
- 所有数据按 `tenant_id` 隔离
- 不同租户数据互不可见

## 🚀 安装部署

### 1. 导入菜单配置


登录后台管理界面，进入 **权限管理** → **菜单规则**，找到"工作流"菜单，为相应角色分配权限。

- 审批中心：`/admin/workflow/approval/index`

## 📝 使用流程

### 步骤1：配置业务模块

1. 进入 **业务模块接入** 页面
2. 选择要启用的模块（如 HR-请假）
3. 配置业务表名、状态字段、审批状态值
4. 选择默认审批流程

**示例配置：**
```
模块标识：hr_leave
业务表名：hr_leave
标题字段：title
状态字段：status
审批中值：0
通过值：1
拒绝值：2
```

### 步骤2：创建审批流

1. 进入 **审批流定义** 页面
2. 点击"新建流程"
3. 填写流程名称（如"请假审批流程"）
4. 选择所属业务模块（如"HR-请假"）
5. 保存后进入节点配置

### 步骤3：配置审批节点

1. 点击"节点配置"按钮
2. 点击"添加审批节点"
3. 配置节点信息：
   - 节点名称（如"部门主管审批"）
   - 审批人类型（如"部门负责人"）
   - 审批方式（如"或签"）
   - 触发条件（可选）
4. 支持拖拽排序节点顺序
5. 点击"保存节点"

### 步骤4：发起审批（业务代码集成）

```php
use app\common\service\workflow\WorkflowEngine;

try {
    $result = WorkflowEngine::start(
        $tenantId,           // 租户ID
        'hr_leave',          // 模块标识
        $businessId,         // 业务单据ID
        $initiatorId,        // 发起人ID
        [
            'business_title' => '张三的请假申请',  // 业务标题（可选）
            'initiator_select' => [               // 发起人自选的审批人（可选）
                1 => [123, 124],  // 节点序号 => [管理员ID列表]
            ]
        ]
    );
    
    // 审批实例创建成功
    $instanceNo = $result['instance_no'];  // 实例编号：WF2026041500001
    
} catch (\Throwable $e) {
    // 创建失败
    echo $e->getMessage();
}
```

### 步骤5：处理审批

1. 审批人进入 **审批中心**
2. 在"待我审批"标签查看待处理任务
3. 点击"通过"、"拒绝"或"转交"
4. 填写审批意见
5. 系统自动推进到下一节点

## 🔧 高级功能

### 条件触发示例

配置节点触发条件，实现差异化审批路径：

**场景1**：金额 <= 5000元，跳过总经理审批
```
条件逻辑：AND
条件项：
  - 字段：amount, 运算符：lt, 值：5000
```

**场景2**：请假天数 > 3天 或 级别 = 经理，需要HR审批
```
条件逻辑：OR
条件项：
  - 字段：days, 运算符：gt, 值：3
  - 字段：level, 运算符：eq, 值：经理
```

### 撤回功能

- 仅在第一个审批节点时允许撤回
- 审批已进入第二节点后不可撤回
- 撤回后业务单据状态恢复为"草稿"

### 转交功能

- 审批人可将任务转交给其他管理员
- 转交后原任务状态变为"已转交"
- 新审批人收到新的待审批任务

## 💡 最佳实践

1. **流程设计**：建议审批节点不超过5个，避免流程过长
2. **审批人配置**：优先使用"部门负责人"，减少手动维护成本
3. **条件使用**：合理设置触发条件，避免所有流程都走全节点
4. **测试流程**：正式使用前，先在测试环境完整测试审批流程
5. **权限控制**：为不同角色分配适当的审批权限

## 🐛 常见问题

### Q1: 审批流保存后看不到节点？
A: 请确保至少添加了一个审批节点，并点击"保存节点"按钮。

### Q2: 发起审批时报错"未解析到审批人"？
A: 检查审批人配置：
- 管理员指定：确认选择了管理员
- 部门负责人：确认发起人有关联部门且部门有负责人
- 发起人自选：确认发起时已选择审批人

### Q3: 业务单据状态没有自动更新？
A: 检查模块配置：
1. 业务表名是否正确
2. 状态字段名是否正确
3. 审批通过/拒绝值是否与业务表一致

### Q4: 菜单权限如何配置？
A: 执行 `database/workflow_menu.sql` 后，在后台权限管理中为相应角色分配"工作流"相关权限。
