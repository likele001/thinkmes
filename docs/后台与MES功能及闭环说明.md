# 后台管理框架与 MES 功能梳理及闭环说明

## 一、后台管理框架功能（非 MES）

基于 ThinkPHP + 多租户的通用后台，主要模块如下。

### 1. 系统与权限

| 模块 | 路径/控制器 | 功能说明 |
|------|-------------|----------|
| 权限规则 | `auth_rule` | 菜单与权限节点管理（树形）、规则增删改 |
| 管理员 | `admin` | 后台账号、角色绑定、规则授权 |
| 角色 | `role` | 角色管理、分配权限规则 |
| 个人中心 | `profile` | 当前管理员资料、修改密码等 |

### 2. 多租户与平台

| 模块 | 路径/控制器 | 功能说明 |
|------|-------------|----------|
| 租户管理 | `tenant` | 租户列表、添加/编辑/禁用、套餐与权限 |
| 租户审核 | `tenant_audit` | 租户注册审核、通过后自动授权 |
| 租户注册 | `register` / `tenant_register` | 租户自助注册 |
| 套餐管理 | `tenant_package` | 套餐定义、功能点（对应 auth_rule） |
| 套餐功能 | `tenant_package_feature` | 套餐与权限规则关联 |
| 租户订单 | `tenant_order` | 租户购买/续费套餐订单（若启用） |
| 租户小程序 | `tenant_miniapp` | 租户绑定微信小程序 AppID/AppSecret 等 |

### 3. 通用能力

| 模块 | 路径/控制器 | 功能说明 |
|------|-------------|----------|
| 首页/仪表盘 | `index` | 后台首页、菜单接口、清除缓存等 |
| 配置 | `config` | 系统参数配置 |
| 附件 | `attachment` | 上传文件管理 |
| 操作日志 | `log` | 操作记录、导出 |
| 插件 | `addon` | 插件安装/卸载/启用/禁用、配置（如云存储） |

## 二、MES 制造执行系统功能清单

所有 MES 功能均在 `mes` 分组下，按业务域整理如下。

### 1. 基础主数据

| 菜单/模块 | 控制器 | 主要功能 |
|-----------|--------|----------|
| **客户管理** | `mes/Customer` | 客户列表、添加/编辑/删除 |
| **供应商管理** | `mes/Supplier` | 供应商列表、添加/编辑/删除 |
| **产品管理** | `mes/Product` | 产品列表、添加/编辑/删除（产品线） |
| **产品型号** | `mes/ProductModel` | 型号列表、添加/编辑、关联产品与工序 |
| **工序管理** | `mes/Process` | 工序列表、添加/编辑/删除 |
| **工序工价** | `mes/ProcessPrice` | 型号×工序工价、批量设置、计件/计时单价 |
| **工序路线** | `mes/ProcessRoute` | 工艺路线（工序顺序）维护 |
| **物料管理** | `mes/Material` | 物料列表、添加/编辑、库存、单价等 |
| **BOM 管理** | `mes/Bom` | BOM 列表、添加/编辑/删除、BOM 明细、审核 |

### 2. 订单与物料

| 菜单/模块 | 控制器 | 主要功能 |
|-----------|--------|----------|
| **订单管理** | `mes/Order` | 订单列表、添加/编辑/删除、订单型号与数量；按 BOM 计算物料需求、订单物料清单、缺料与采购状态 |

### 3. 生产计划与任务分配

| 菜单/模块 | 控制器 | 主要功能 |
|-----------|--------|----------|
| **生产计划** | `mes/ProductionPlan` | 计划列表、添加/编辑、关联订单与型号；计划进度、计划下分工查看、统计完成量 |
| **任务分配** | `mes/Allocation` | 分配列表、添加/编辑/删除、批量分配（支持按计划批量分配并写入 plan_id）；分配二维码生成 |

### 4. 报工与审核

| 菜单/模块 | 控制器 | 主要功能 |
|-----------|--------|----------|
| **报工管理** | `mes/Report` | 报工列表、添加/编辑/删除；审核页、审核通过/拒绝（含质检状态、审核备注与媒体）；审核通过后：计件生成追溯码、完工入库、工资写入 |

### 5. 工资与追溯

| 菜单/模块 | 控制器 | 主要功能 |
|-----------|--------|----------|
| **工资管理** | `mes/Wage` | 工资列表、统计（按员工/时间等） |
| **追溯码** | `mes/TraceCode` | 追溯码列表（code_type=1）、单个/批量生成、关联报工与分配 |

### 6. 仓储与采购

| 菜单/模块 | 控制器 | 主要功能 |
|-----------|--------|----------|
| **仓库管理** | `mes/Warehouse` | 仓库列表、添加/编辑 |
| **库存管理** | `mes/Stock` | 库存查询、生产领料（出库）、库存流水、库存盘点 |
| **采购管理** | `mes/Purchase` | 采购申请、审核、采购入库（订单需求可触达采购） |

### 7. 质量、发货与售后

| 菜单/模块 | 控制器 | 主要功能 |
|-----------|--------|----------|
| **质检管理** | `mes/Quality` | 质检标准、质检记录、质检统计 |
| **发货管理** | `mes/Shipment` | 发货列表、创建发货、选订单、确认签收、物流跟踪 |
| **售后管理** | `mes/AfterSales` | 售后单列表、添加/编辑/删除（可与追溯码/订单关联） |

### 8. BI 与看板

| 菜单/模块 | 控制器 | 主要功能 |
|-----------|--------|----------|
| **MES 首页** | `mes/Mes` | MES 入口页 |
| **BI 报表** | `mes/Bi` | 仪表盘数据、生产效率、质量分析、成本分析（按时间/租户） |

## 三、MES 业务闭环分析

### 3.1 主流程闭环（订单 → 交付）

```
客户/订单 → 订单管理(含型号与数量)
    ↓
BOM 物料需求计算 → 订单物料清单、缺料、采购申请
    ↓
生产计划(按订单/型号) → 计划进度
    ↓
任务分配(可带 plan_id) → 分配编码、工序、员工、数量
    ↓
员工报工(计件/计时) → 报工列表
    ↓
报工审核(通过/拒绝、质检) → 通过后：
    ├─ 完工入库(成品)
    ├─ 计件追溯码生成
    └─ 工资记录
    ↓
发货管理(选订单/数量) → 签收、物流
    ↓
售后(可选，按订单/追溯)
```

- **订单 → 计划 → 分配 → 报工 → 审核**：数据链完整（订单→计划 plan_id→分配 plan_id→报工 allocation_id→审核更新状态并写追溯/入库/工资）。
- **分配与计划**：批量分配已支持 `plan_id`，计划下的分工与进度统计可正确关联。
- **报工审核**：通过后自动写追溯码（含 code_type/route_id）、库存（完工入库）、工资，与追溯码列表、库存、工资模块形成闭环。

### 3.2 物料与库存闭环

```
订单 → 按 BOM 计算物料需求 → 订单物料(需量、缺料)
    ↓
采购申请(可自动/手动) → 采购审核 → 采购入库 → 库存增加
    ↓
生产领料(出库) → 库存减少、领料记录
    ↓
报工审核通过 → 完工入库(成品型号入库)
```

- 订单物料清单、缺料、采购、入库、领料、完工入库、库存流水/盘点 均存在，可形成**从需求到库存变动**的闭环。

### 3.3 质量与追溯闭环

- **报工审核**：支持质检状态（合格/不合格），与报工、工资可联动。
- **追溯码**：审核通过后自动生成（或追溯码模块补生成），关联 report_id、allocation_id、order_id、model_id、工序、员工、item_no 等，**从成品/单件可追溯到订单与工序**。
- **售后**：可基于订单或追溯信息做售后单，形成**交付后反馈**闭环。

### 3.4 结论：能否形成完整闭环

| 维度 | 是否闭环 | 说明 |
|------|----------|------|
| 订单→计划→分配→报工→审核 | 是 | 关联字段完整（含 plan_id），审核后写追溯、入库、工资 |
| 物料需求→采购→入库→领料 | 是 | 订单物料、采购、库存、领料、盘点均具备 |
| 报工→工资 | 是 | 审核通过写工资，工资模块可查询与统计 |
| 报工→追溯 | 是 | 审核生成追溯码（code_type/route_id 已修复），追溯码列表可查 |
| 报工→成品入库 | 是 | 审核通过调用完工入库（StockLogModel） |
| 订单→发货→签收 | 是 | 发货选订单、签收、物流跟踪 |
| 售后 | 部分 | 有售后单与列表，与订单/追溯的深度联动可按需再加强 |

**总体结论**：当前后台框架 + MES 已能形成**从订单录入、计划与分配、报工与审核、到工资/追溯/入库、再到发货与售后**的完整业务闭环；主数据、仓储采购、质量与 BI 均参与该闭环，仅售后与订单/追溯的自动关联可后续再增强。

```
       \ [工序路线]       |           → [生产计划] → [任务分配]
        \________________|                    |            |
                                         [计划进度]   [报工] → [审核]
                                                              |
                                    [工资] ← [追溯码] ← ______|

                                    [发货] → [签收/物流]

```
