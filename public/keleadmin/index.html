KeleAdmin 多租户后台 · MES 一体化

基于 ThinkPHP 8 的后台管理框架，内置权限、多租户、套餐与完整 MES 制造执行系统。
从订单、计划、分配到报工、工资、追溯、仓储，形成完整业务闭环。

框架特性

多租户

租户注册、审核、套餐与功能授权，按租户隔离数据与权限。

权限规则

菜单与权限树、角色授权，支持按租户分配可见菜单。

MES 制造执行

订单、BOM、计划、分配、报工、工资、追溯、仓储、采购、质检、发货、售后、BI。

小程序支持

员工端报工、管理端看板，同一小程序双身份，租户小程序配置对接。

技术栈

  • 后端 ThinkPHP 8
  • 前端 Bootstrap 5 · CoreUI · Bootstrap Table
  • 数据库 MySQL
  • 多应用 think-multi-app
  • 扩展 插件机制 · 云存储等
