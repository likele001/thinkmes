功能模块说明 给租户和业务人员看的使用指南

本文档用通俗易懂的方式，介绍 KeleAdmin 中各个功能模块的作用、适用角色、典型操作场景以及需要特别注意的业务要点。
目标是让企业老板、生产主管、仓库/采购、质检、财务和一线员工，都能看懂并用起来。

一、整体业务闭环总览

整个系统围绕“多租户后台 + MES 制造执行”搭建，从接单开始，一直连到发货、售后和数据分析，中间贯穿物料、采购、库存、质检和工资。

  • 业务、计划、生产、仓库、采购、质检、财务：各自使用对应模块完成日常工作。
  • 一线员工和客户：通过扫码页面、小程序完成报工、查工资、查追溯等操作。

二、主要模块详解（照着业务来理解）

下面不再用表格，而是按“这个模块是干嘛的 / 系统里怎么用 / 你实际要怎么点 / 举个例子”这几个角度，把主要模块拆开讲一遍，风格跟 BOM 说明保持一致，方便你给老板、车间和实施同事讲解。

1. BOM 管理：产品的“配方”

用你现在的这个系统来说，BOM 就是“某个产品型号需要哪些物料、各要多少”的标准配方，系统后来所有的：

  • 订单物料需求（要多少物料）
  • 缺料判断
  • 自动生成采购申请
  • 预估成本

都是根据 BOM 算出来的。

1.1 BOM 到底是干嘛的？

直白说：做“产品 A 型号 X”需要的那张“用料清单”，录进系统后，这张清单就是 BOM。

  • 算需求量：订单下了 100 个，系统按 BOM 直接算出每种物料要多少。
  • 算损耗：BOM 里有损耗率，系统会用“需求量 × (1 + 损耗率)”多算一点。
  • 算物料成本：结合物料单价，算出订单预估物料成本。
  • 判断缺料：拿需求量对比库存，算出缺料数量。
  • 自动生成采购申请：缺料且有供应商，就自动生成采购申请。

可以把它理解成：只要 BOM 配好了，后面“算料 + 算钱 + 提前采购”系统都能帮你自动干。

1.2 在系统里怎么被用上的？

当你保存订单时，后台会按照订单里的产品型号，去查这个型号的“已发布 BOM”，然后：

  • 按订单数量 × BOM 用量 × (1 + 损耗率) 计算每种物料的需求量。
  • 把需求量、预估单价、预估金额写进订单物料表。
  • 对比物料库存，不够的部分生成采购申请。

1.3 实际操作怎么用？（一步一步）

  • 先建物料：MES → 物料管理，录名称、规格、单位、价格、默认供应商。
  • 建产品和型号：产品管理建大类，产品型号管理建具体型号。
  • 在 BOM 管理中新建 BOM：
    1. 选产品型号，设版本号、基数（一般 1）。
    2. 在明细里逐行添加物料、用量、损耗率。
    3. 先保存为草稿，确认无误后改为“已发布”。
  • 之后订单只要选这个型号，系统就会按 BOM 自动算料和缺料。

1.4 举个例子

型号“智能灯 A 型”，BOM 配：灯壳 1 个、灯珠 20 颗（损耗 2%）、电源模块 1 个、包装盒 1 个。订单来 100 个：

  • 灯壳：100 个
  • 灯珠：100 × 20 × (1 + 2%) ≈ 2040 颗
  • 电源模块：100 个
  • 包装盒：100 个

系统再去比库存，不够的自动出采购申请，后面的采购、入库、领料全是围绕这一套数据走。

2. 工艺路线管理：产品要走哪些工序

工艺路线就是“这个型号从原料到成品，要经过哪些工序、顺序如何、哪些必做、哪些可选”的标准流程，是分工、报工和追溯的基础。

2.1 工艺路线是干嘛的？

  • 规定生产顺序：折弯 → 焊接 → 打磨 → 装配 → 测试 → 包装。
  • 标记关键工序：哪些必须做，哪些是可选/分支工序。
  • 为分工分配提供模板：分工时可以直接按路线拆任务。
  • 为追溯码提供“工艺轨迹”：客户扫码时能看到每道工序信息。

2.2 在系统里怎么被用上的？

  • 分工时，可以按某个型号的默认工艺路线，自动带出工序列表。
  • 报工记录会挂在具体工序上，后续汇总工资、看瓶颈都基于这些数据。
  • 追溯码详情页会按工艺路线顺序展示生产过程。

2.3 实际操作怎么用？

  • 先在“工序管理”里把常用工序维护好。
  • 进入 MES → 工艺路线管理，新建路线：
    1. 选择产品型号，填写路线名称（如“标准工艺路线 A”）。
    2. 在步骤里按顺序添加工序，勾选“必做/可选/分支”等标记。
    3. 保存并设为该型号的默认路线。

3. 订单管理 + 订单物料清单：从接单到“算料”

订单管理记录客户需求，订单物料清单则是“这张订单需要哪些物料、各多少、缺多少、要花多少钱”的结果。

3.1 这两个模块干嘛的？

  • 订单管理：把客户、型号、数量、交期记清楚，是所有后续动作的起点。
  • 订单物料清单：把 BOM + 订单数量算出来的物料需求集中展示，顺带算缺料和预估成本。

3.2 在系统里怎么被用上的？

  • 保存订单时，系统自动生成订单物料清单。
  • 采购申请、生产领料、订单成本分析都基于这张清单。

3.3 实际操作怎么用？

  • 新建订单：选客户、选产品型号、填数量和交期，保存。
  • 在订单列表中点击“物料清单”，查看：
    • 需求数量、库存数量、缺料数量。
    • 预估单价和预估金额。
  • 根据缺料情况安排采购和生产顺序。

4. 采购申请 + 采购入库：从缺料到有料

这两个模块配合使用：采购申请收集“要买什么、买多少”，采购入库记录“实际到了多少、进了哪个仓”。

4.1 它们干嘛的？

  • 采购申请：把所有缺料集中起来，方便采购统一谈价、统一下单。
  • 采购入库：记录实际收货，更新库存，并回写订单物料状态。

4.2 在系统里怎么被用上的？

  • 订单保存后，系统按缺料自动生成采购申请。
  • 从采购申请生成入库单，会自动：
    • 增加库存。
    • 把采购申请标记为“已采购”。
    • 把对应订单物料标记为“已入库/已备料”。

4.3 实际操作怎么用？

  • 进入采购申请列表，按状态筛选“待审核”，逐条确认后通过。
  • 物料到货后，在采购入库中新建入库单：
    1. 选择采购申请。
    2. 填写实到数量、入库仓库、到货日期。
    3. 保存，库存和订单物料状态自动更新。

5. 库存管理 + 生产领料：仓库视角看物料

库存管理让你站在仓库角度看“现在有多少”；生产领料则控制“给生产发出去多少”。

5.1 它们干嘛的？

  • 库存管理：按物料和仓库查看当前库存，判断是否低于安全库存。
  • 生产领料：根据订单物料生成出库单，把料从仓库发到车间。

5.2 实际操作怎么用？

  • 库存管理里按物料名称、仓库过滤，关注库存预警。
  • 生产领料：
    1. 从订单物料生成领料单。
    2. 确认出库数量、领料人、出库仓库。
    3. 保存后库存减少，对应订单物料标记为“已出库”。

6. 分工分配 + 报工管理 + 工资管理：从任务到工资

这三个模块是一条线：先把任务分给谁，再让员工报工记录完成量，最后按工价算工资。

6.1 它们干嘛的？

  • 分工分配：明确“这道工序谁来做、做多少、什么时候做”。
  • 报工管理：记录员工实际完成情况，并进行审核。
  • 工资管理：按报工 × 工价统计计件工资。

6.2 在系统里怎么被用上的？

  • 分工时生成任务二维码，员工扫码报工。
  • 只有审核通过的报工会进入工资统计和产品追溯。
  • 工资管理按员工和时间段汇总所有工序报工金额。

6.3 实际操作怎么用？

  • 分工：
    1. 在分工模块里选订单、工序、员工/班组、任务数量。
    2. 保存并打印/导出任务二维码。
  • 报工：
    1. 员工扫码进入报工页面。
    2. 填完成数量、不良数量、异常说明。
    3. 提交后等待班组长/主管审核。
  • 工资：
    1. 进入工资管理，按月份、员工过滤。
    2. 确认各工序报工金额，导出工资表给财务发放。

7. 质检管理 + 追溯码 + 客户扫码追溯：质量闭环

这几个模块合起来，就是“内部管控质量 + 对外给客户看的质量证明”。

7.1 它们干嘛的？

  • 质检管理：定义质检项目，记录检验结果。
  • 追溯码管理：生成和管理成品追溯码。
  • 客户扫码追溯：客户通过二维码查看产品生产和质检信息。

7.2 在系统里怎么被用上的？

  • 质检记录会关联到具体报工/批次。
  • 追溯码生成后，绑定报工、质检、图片/视频等信息。
  • 客户扫码打开的是一个无需登录的 H5 页面，只展示对客户有价值的信息。

7.3 实际操作怎么用？

  • 在质检模块里维护标准，并按批次录入质检结果。
  • 报工审核通过后，在追溯码管理中为成品生成追溯码，导出二维码贴在产品上。
  • 客户扫描后即可查看对应批次的生产和质检记录。

8. 租户、管理员与角色：谁能看到什么

这部分主要是平台和租户管理员关心，用来控制“哪些公司能用系统、公司内部谁能看到哪些菜单”。

  • 租户管理：平台维护每个企业的基本信息、状态、到期时间。
  • 套餐与授权：决定某个租户开放哪些功能模块。
  • 管理员与角色：在租户内部设置不同岗位的后台账号和权限。

实际落地时，一般做法是：按岗位建角色（如“生产主管”“仓库主管”“财务”），再把账号绑定到对应角色上，让每个人只看到自己需要的菜单。

9. 模块速查图表（给人培训时一眼扫一遍）

上面是按模块拆开的详细说明，这里保留一份“总览表”，方便你在给别人培训或自己回顾时，快速扫一眼整个系统有哪些模块、谁用、干嘛用。

模块分组 模块名称 主要使用角色 核心用途 典型操作 关键提醒
平台与租户 租户管理 平台超级管理员 管理所有企业租户的基本信息、状态、到期时间。 审核租户注册、开通/关闭租户、设置到期日。 只面向平台方，普通企业管理员一般无权操作。
套餐与授权 平台超级管理员 定义套餐内容，控制每个租户可用的功能模块。 创建套餐、勾选可用菜单、给租户分配套餐。 变更套餐会影响租户能看到的菜单，需提前沟通。
管理员与角色 租户管理员 管理本企业后台登录账号及其角色和权限。 新增管理员、给角色分配菜单、为管理员绑定角色。 建议按岗位建角色，如“生产主管”“仓库主管”。
租户注册入口 平台方、意向客户 提供在线申请入口，意向客户自行提交企业信息。 在官网或登录页展示“申请试用/租户注册”的入口。 注册提交后需在平台后台审核后才能正式使用。
基础资料 客户管理 业务、销售、租户管理员 维护客户名称、联系人、电话等，下订单时可直接选择。 新增客户、更新联系人、查看历史订单情况。 真实准确的客户资料有利于后续对账和售后。
供应商管理 采购、租户管理员 维护物料供应商信息，在物料和 BOM 中可设默认供应商。 新增供应商、记录联系人、备注结算方式。 建议为关键物料设定主供应商，方便自动生成采购申请。
物料管理 采购、仓库、工艺 维护所有原材料和部件信息，包括单位、规格、价格和库存。 新增物料、调整当前价格、查看库存和最低库存预警。 库存字段由“入库/领料”自动变动，慎重手工修改。
仓库管理 仓库主管 定义原材料仓、成品仓等不同仓库，用于统计和管理。 新增仓库、停用不用的仓库、在物料上指定归属仓库。 建议先规划好仓库结构，再大量上架物料。
产品管理 业务、工艺 管理产品大类，比如“电机”“控制柜”等。 新增产品大类、绑定产品型号。 一般不直接参与生产，用作型号的分类。
产品型号管理 业务、工艺 维护具体型号，如“电机 A1”，是订单、BOM、工艺路线的核心对象。 为每个产品添加多个型号、设置型号编码和状态。 下订单、BOM、工艺路线都基于型号，请务必维护准确。
工序管理 工艺、生产主管 维护生产过程中的各道工序，如折弯、焊接、装配、测试。 新增工序、调整工序名称、停用老工序。 工序名称会出现在报工和工资明细中，应简洁易懂。
工序工价管理 财务、生产主管 为不同工序（可按型号区分）设置计件单价，用于自动算工资。 为常用工序设置单价、按需要周期性调整。 工价调整会直接影响工资，请经管理层确认后修改。
产品设计 BOM 管理 工艺、技术 定义“做 1 个成品需要哪些物料、各多少、损耗多少”，用于自动算料和成本。 按型号创建 BOM、添加物料用量和损耗率、发布生效版本。 只有“已发布”的 BOM 会用于订单物料计算，建议先测试后发布。
工艺路线管理 工艺、生产主管 定义产品型号需要经过哪些工序、顺序如何，哪些必做、哪些可选。 按型号配置工艺路线、设置默认路线、维护工艺步骤。 后续分工和追溯可以依赖工艺路线，建议至少维护一条标准路线。
订单与生产 订单管理 业务、生产计划 录入客户订单，是后续生产和物料计算的起点。 新建订单、选择客户和产品型号、填写数量和交期。 保存订单后会自动计算物料需求并检查缺料。
生产计划 生产计划、车间主任 根据订单安排生产计划，确定何时生产哪些型号、多少数量。 按订单创建计划、调整计划日期和优先级。 计划越清晰，后面的分工和产能安排就越顺畅。
分工分配 生产主管、班组长 将计划任务拆分到具体员工/班组，指定工序和数量，并生成二维码。 为某订单和工序分配任务、打印或导出任务二维码。 分工后生成的码主要用于内部跟踪和员工报工，不直接给客户。
报工管理 一线员工、班组长、生产主管 记录员工实际完成的工序数量、合格/不合格情况、时间等。 员工扫码报工、管理员审核报工、查看报工记录和统计。 只有审核通过的报工才会计入工资和产品追溯。
质检管理 质检员、质量主管 维护质检标准、记录质检结果，用于控制质量和分析不良。 按产品/工序定义质检标准、录入质检记录、查看统计。 质检结果会出现在产品追溯页面，建议真实、可追溯。
工资管理 财务、人事、车间主任 根据报工记录和工序工价，自动汇总员工计件工资。 按员工和时间段查询工资、导出工资表。 工价和报工数据决定工资结果，审核流程要规范。
物料、采购与库存 订单物料清单 采购、仓库、生产计划 展示某个订单按 BOM 计算出的物料需求、缺料数量和预估成本。 从订单进入物料清单，查看每种物料的需求、库存和缺口。 此处可以快速判断是否需要紧急采购或调整生产顺序。
采购申请 采购、物控 集中管理所有缺料的采购需求，可按供应商和状态查看。 根据订单自动生成申请、人工补充特殊物料、审核通过或驳回。 系统会尽量避免重复申请，建议按物料和时间统一审核。
采购入库 仓库、采购 记录实际到货并入库，增加库存，并回写订单物料的采购状态。 选择采购申请生成入库单、录入实际到货数量和仓库。 尽量通过申请生成入库，确保订单物料状态和库存一致。
库存管理 仓库主管、物控 查看所有物料的当前库存、预警情况。 按物料名称、仓库查询库存、关注低于最低库存的物料。 真正的库存变化来自入库和出库，建议减少手工调整。
生产领料（出库） 仓库、生产 根据订单物料生成领料单，从仓库发料到生产现场。 按订单物料创建出库单、确认出库数量和领料人。 出库数量通常等于订单需求量，如有差异建议备注原因。
库存流水 仓库主管、财务 记录每一次出入库的明细，用于追踪库存变化原因。 按物料和时间段查看流水、导出数据用于盘点核对。 常见类型包括采购入库、生产领料、发货出库等。
追溯与售后 追溯码管理 生产主管、质量、售后 管理系统中所有追溯码，特别是贴在成品上的最终追溯码。 按报工记录生成成品追溯码、导出二维码、按码查询记录。 给客户的应是报工审核后生成的成品码，避免内部分工码混用。
客户扫码追溯 客户、售后 客户扫描产品追溯码，查看生产、质检、图片等关键信息。 在产品上印刷或粘贴二维码，客户即可扫码查看。 页面无需登录，应保证内容简洁可信，避免泄露敏感内部信息。
售后管理 售后工程师、质量 记录客户反馈的问题、处理过程和结果，便于质量改进。 建立售后记录、关联追溯码、记录处理过程和结果。 结合追溯信息，可快速分析问题批次和原因。
员工端与小程序 员工扫码报工 一线员工 员工通过扫码快速进入报工界面，录入自己完成的工作量。 扫任务二维码、选择工序、填写完成数量和异常说明。 操作尽量简单，减少员工学习成本，保障数据准确性。
员工工资查询 一线员工 员工查看自己某段时间的计件工资明细。 通过手机端选择月份，查看各工序报工对应的收入。 可减少工资结算环节的沟通成本和误解。
管理端看板 车间主任、厂长 通过手机端查看当日产量、在制情况、关键指标。 打开小程序管理端，看实时数据和趋势。 适合作为现场管理的辅助工具，并非所有租户都必须启用。
报表与 BI 数据看板/BI 老板、管理层 以图表方式展示生产效率、质量情况、成本和订单执行情况等。 查看首页 BI 报表、筛选时间范围和维度、导出数据。 数据来源于日常业务，只有规范使用各模块，报表才有意义。

三、推荐落地顺序

为了让企业在不增加太多负担的前提下快速上线，建议按以下顺序逐步启用模块：

  1. 先完成租户配置、管理员和角色划分，明确谁管什么。
  2. 维护基础资料：客户、供应商、物料、仓库、产品和产品型号。
  3. 为主要型号配置 BOM 和基本工艺路线，先覆盖 80% 的主力产品。
  4. 从新订单开始，通过订单 → 物料清单 → 采购申请 → 入库，把“算料+备料”打通。
  5. 上线分工、报工和工资模块，让一线员工先从“简单报工”开始。
  6. 在生产稳定后，逐步引入质检、追溯和售后模块，构建质量闭环。
  7. 最后再结合 BI 报表，做效率、成本和质量的综合分析。

四、主要模块操作示例（一步一步教）

本节不讲原理，只讲“要点在哪、要点怎么点”，按常用模块给出最常见的一条操作路径，方便业务和一线同事照着做。

1. 客户管理：先把客户录进去

适用角色：业务、租户管理员。目的：下订单时可以直接选择客户，而不是每次手打名称。

  • 后台菜单路径：进入后台 → 左侧菜单选择“客户管理”。
  • 添加客户步骤：
    1. 点击右上角或列表上方的“添加”按钮。
    2. 在弹出的表单中填写客户名称（必填）、联系人、联系电话等。
    3. 保存即可，后续下订单时就能在下拉框里选到这个客户。
  • 使用建议：客户名称尽量使用全称，例如“重庆某某科技有限公司”，以免后续对账混淆。

2. 物料管理：把常用原材料录完整

适用角色：采购、仓库、工艺。目的：为 BOM、采购和库存打基础。

  • 后台菜单路径：进入后台 → MES → 物料管理。
  • 添加物料步骤：
    1. 点击“添加”按钮。
    2. 填写物料名称（如“螺丝 M4×10”）、规格型号、计量单位（个、米、KG 等）。
    3. 可选：填写当前采购单价、默认供应商、最低库存。
    4. 保存后，该物料可以在 BOM 中被引用，也可以用于采购和库存。
  • 使用建议：同一类物料命名风格保持统一，便于搜索和统计。

3. 产品与产品型号：把你实际卖的东西建出来

适用角色：业务、工艺。目的：后面所有订单、BOM、工艺路线都围绕“产品型号”展开。

  • 后台菜单路径：进入后台 → MES → 产品管理 / 产品型号管理。
  • 操作步骤：
    1. 先在“产品管理”中添加产品大类，例如“电机”、“配电柜”。
    2. 再在“产品型号管理”中：
      • 选择所属产品大类。
      • 填写型号名称（例如“电机 A1 型”）。
      • 可填写型号编码、备注等。
    3. 保存后，这个型号可以被订单、BOM、工艺路线引用。
  • 使用建议：一个实际销售型号，对应系统里一个“产品型号”，不要混在一起用“其它”等模糊名称。

4. BOM 管理：教系统自动帮你算料

适用角色：工艺、技术。目的：让系统知道“做一台成品需要哪些物料、各要多少”，后续自动算订单物料需求。

  • 后台菜单路径：进入后台 → MES → BOM 管理。
  • 为某个型号配置 BOM 的步骤：
    1. 在列表中点击“添加”或“新建 BOM”。
    2. 选择产品型号，例如“电机 A1 型”。
    3. 填写版本号（例如 V1.0）、基数（一般填 1，表示“1 台成品”）。
    4. 在明细区域逐行添加物料：
      • 选择物料（下拉框里是刚才在“物料管理”里的物料）。
      • 填写用量，例如“4”（代表 1 台成品用 4 个）。
      • 需要时填写损耗率，例如“2%”。
    5. 保存后，先以“草稿”状态检查无误，再点击“发布/审核通过”，让此 BOM 生效。
  • 使用建议：如果后续改版，可以新建高版本 BOM，旧版本保留，避免直接覆盖历史配置。

5. 订单管理：从客户订单开始驱动生产

适用角色：业务、生产计划。目的：记录客户需求，并让系统自动算出需要哪些物料。

  • 后台菜单路径：进入后台 → MES → 订单管理。
  • 新增订单的步骤：
    1. 点击“添加订单”。
    2. 在订单头部选择客户、填写订单名称或订单号、交货日期等。
    3. 在下方“产品型号”区域：
      • 点击“添加一行”。
      • 选择产品型号。
      • 填写数量，例如“100 台”。
    4. 保存订单。
  • 保存后的系统行为（业务人员不需要操作，但要知道）：
    • 根据该型号的已发布 BOM，自动计算所需物料数量。
    • 对照库存，标记哪些物料缺料，并生成对应的采购申请。
  • 查看订单物料清单的步骤：
    1. 在订单列表中找到刚才的订单。
    2. 点击“物料清单”按钮。
    3. 在弹出的页面中，查看每种物料的需求数量、当前库存、缺料数量和预估金额。

6. 采购流程：从缺料到入库

适用角色：采购、仓库。目的：根据订单缺料，做采购申请和入库。

  • 采购申请查看与审核：
    1. 进入后台 → MES → 采购管理 → 采购申请。
    2. 按“待审核”状态筛选，查看系统自动生成的申请。
    3. 逐条确认物料、数量和供应商，点击“审核通过”或“驳回”。
  • 根据采购申请入库：
    1. 进入后台 → MES → 采购管理 → 采购入库。
    2. 点击“添加入库单”。
    3. 选择对应的采购申请，系统会自动带出物料信息。
    4. 填写实际到货数量、入库时间、选择入库仓库。
    5. 保存后，系统会：
      • 增加该物料库存。
      • 把采购申请状态改为“已采购”。
      • 把对应订单物料标记为“已入库/已备料”。

7. 分工与报工：把任务分给人，并收集产量

适用角色：生产主管、班组长、一线员工。目的：知道谁在做什么、做了多少，为工资和追溯打基础。

  • 分工分配：
    1. 进入后台 → MES → 分工/分配管理。
    2. 选择一个订单和型号，选择要分配的工序。
    3. 选择员工或班组，填写分配数量。
    4. 保存后，可以导出或打印该任务的二维码。
  • 员工扫码报工：
    1. 员工用手机打开扫码页面或小程序，扫描任务二维码。
    2. 进入报工界面，确认工序和任务信息。
    3. 填写本次完成数量、不良数量等信息。
    4. 提交后，等待班组长或管理员审核。
  • 报工审核：
    1. 进入后台 → MES → 报工管理 → 报工审核。
    2. 按日期或员工筛选待审核记录。
    3. 核对数量、工序和异常说明，点击通过或驳回。

8. 追溯码与客户扫码页面：给客户看的那张“身份证”

适用角色：生产主管、质量、售后、客户。目的：客户扫描成品上的码，可以看到它是怎么生产、怎么质检的。

  • 生成成品追溯码：
    1. 报工审核通过后，进入后台 → MES → 追溯码管理。
    2. 在列表中点击“生成追溯码”或使用批量生成功能。
    3. 系统会为每个已完成的报工记录生成一个“成品码”。
  • 打印或导出二维码：
    1. 在追溯码列表中按条件筛选需要打印的批次。
    2. 导出二维码图片或 PDF，交给生产/包装环节打印贴标。
  • 客户扫码查看：
    1. 客户用手机扫描成品上的二维码。
    2. 自动打开 H5 追溯页面（无需登录）。
    3. 页面展示产品信息、生产工序、质检记录、图片/视频等内容。

9. 工资查询：让员工清楚自己“挣了多少”

适用角色：一线员工、财务、人事。目的：减少工资结算环节的反复沟通。

  • 后台查看工资：
    1. 进入后台 → MES → 工资管理。
    2. 按月份和员工过滤，查看某段时间内每个员工的计件工资。
    3. 导出工资明细给财务做发放依据。
  • 员工端查看工资：
    1. 员工通过手机端登录自己的账号或扫码进入工资页面。
    2. 选择需要查看的月份。
    3. 查看本月各工序的报工数量和对应的金额。
