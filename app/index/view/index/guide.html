ThinkMes 使用指南

从系统配置到日常生产，分章节详细介绍 ThinkMes 的每一项功能。涵盖管理员PC端、员工H5端、客户端完整操作流程。

1. 快速开始

本节介绍如何快速上手 ThinkMes 系统。

1.1 系统简介

ThinkMes 是一款专为中小型制造企业设计的智能MES生产管理系统，主要功能包括：

  • 扫码报工：员工扫码即可完成报工，30秒完成操作
  • 自动算薪：基于报工记录自动计算计件工资
  • 订单管理：全渠道订单管理，客户自助下单
  • 生产排产：可视化甘特图排产，智能派工
  • 质量溯源：一物一码，全流程追溯

2. 系统配置

系统管理员负责创建用户账号、分配角色和管理权限。

2.1 用户管理

操作路径：系统 → 用户管理

  1. 点击 「+ 新建用户」 按钮
  2. 填写用户名（全局唯一）、姓名、密码、部门、手机号
  3. 选择角色（可多选，系统合并权限）
  4. 点击 「保存」 完成创建

2.2 角色管理

操作路径：系统 → 角色管理

系统内置多个角色，建议不要修改：

角色说明核心权限
超级管理员全部权限所有
厂长生产/财务/报表dashboard, report, salary
生产计划员订单/排产/派工order, plan, task
班组长派工审核/报工审核dispatch, report.audit
操作员工报工/查看任务task, report
客户下单/查看进度order.view
财务工资/对账/报表salary, finance

2.3 部门管理

操作路径：系统 → 部门管理

  1. 点击 「+ 新建部门」
  2. 填写部门名称（如"冲压车间""质检部"）
  3. 设置上级部门建立层级关系

3. 主数据管理

产品和型号是两个独立模块，型号关联产品。

3.1 产品管理

操作路径：主数据 → 产品

  1. 点击 「+ 新建产品」
  2. 填写产品编码（唯一）、名称、分类、单位、描述
  3. 支持 Excel 批量导入

3.2 产品型号

操作路径：主数据 → 产品型号

  1. 选择关联的产品
  2. 填写型号编码（唯一）、颜色、材料、规格
  3. 上传多角度图片

3.3 工序管理

操作路径：主数据 → 工序

创建工厂的各个工序（如：下料、冲压、焊接、组装、质检），设置所属车间和标准工时。

3.4 工艺路线

操作路径：主数据 → 工艺路线

  1. 选择产品，输入路线名称
  2. 逐条添加工序步骤，拖拽调整顺序
  3. 设置默认路线

3.5 工序工价

操作路径：主数据 → 工序工价

  1. 选择产品型号
  2. 为每个工序输入单价（元/件）
  3. 支持批量设置

4. 订单管理

4.1 创建订单

操作路径：生产 → 订单管理

  1. 点击 「+ 新建订单」
  2. 选择客户、产品型号、数量、交期
  3. 保存后订单状态为 「草稿」
  4. 确认后自动分解为工单

4.2 订单状态

草稿 → 已确认 → 生产中 → 已完成 → 已发货 / 已取消

5. 生产计划

5.1 排产

操作路径：生产 → 生产计划

  1. 查看待排产工单列表
  2. 在甘特图上拖拽调整起止日期
  3. 系统自动检查物料齐套
  4. 点击 「发布计划」

6. 任务派工

6.1 派工操作

操作路径：生产 → 任务派工

  1. 选择工单，系统按技能标签推荐员工
  2. 选择员工和派工数量
  3. 生成任务二维码，可打印粘贴在工件上
  4. 系统自动推送通知到员工手机端

7. 报工与审核

7.1 员工报工

员工在手机端扫码或手动选择任务，输入合格数/不良数，上传完工照片/视频，提交后立即显示预估工资。

7.2 多级审核

操作路径：生产 → 报工审核

  1. 班组长初审：查看照片/视频，核实数量
  2. QC 终审：质检角度审核
  3. 驳回需填写原因
  4. 支持批量审核

8. 工资管理

8.1 自动计算

操作路径：生产 → 工资管理

公式：月总工资 = Σ(审核通过报工合格数 × 工序工价) + 补贴 - 扣款

  1. 选择月份，系统自动汇总
  2. 查看员工工资明细
  3. 可手动添加补贴或扣款
  4. 确认后生成电子工资条

9. 客户对账

操作路径：财务 → 客户对账单

  1. 选择客户和对账周期
  2. 系统自动列出该周期内所有订单及金额
  3. 核实无误后，对账单发送给客户
  4. 支持导出 PDF/Excel

10. 成本分析

操作路径：财务 → 成本毛利

按订单维度分析：收入、工资成本、物料成本、毛利/毛利率。

11. 员工登录

11.1 登录方式

  1. 在手机浏览器输入 H5 地址
  2. 或扫描工厂发放的二维码
  3. 输入用户名（通常是工号）和密码

12. 扫码报工

这是员工最高频的操作，整个流程不超过 30 秒。

12.1 操作流程

  1. 点击首页 「扫码报工」
  2. 扫描任务二维码
  3. 输入合格数和不良数
  4. 上传完工照片或视频
  5. 点击 「提交」，立即显示预估工资

13. 工资查看

13.1 查看工资

路径：我的 → 工资

选择月份查看计件工资、补贴、扣款、实发金额。

13.2 电子工资条

路径：我的 → 工资条

查看完整工资明细，支持电子签名确认。

14. 客户下单

14.1 下单流程

  1. 底部导航 「下单」
  2. 浏览产品列表，选择型号
  3. 输入订单数量、交期
  4. 点击 「提交订单」

15. 订单追踪

路径：底部导航「追踪」

时间线视图显示各工序完成状态，自动刷新。

16. 常见问题

Q: 订单确认后发现型号错了？

已确认的订单不可修改。操作：作废该订单 → 新建正确的订单。

Q: 报工提交后发现数字填错了？

联系班组长 「驳回」 该报工，然后重新报工。

Q: 工资计算有误？

进入工资管理查看明细，每笔报工的数量和金额都有记录。

Q: 忘记密码怎么办？

联系管理员重置密码。
